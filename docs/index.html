Xuan Theme

Xuan · 宣纸 · 统一色系主题

同一套主色体系，同步覆盖 Obsidian、Zed、VS Code。安静、留白、可长期使用。

Obsidian 下载 Zed 下载 VS Code 下载 GitHub

Obsidian

主入口（Obsidian 唯一入口）

  • 主题文件：obsidian/theme.css
  • 清单文件：obsidian/manifest.json
  • 安装步骤： cp /你的仓库路径/xuan-theme/obsidian/theme.css ~/.obsidian/themes/Xuan/theme.css
  • file:// 示例： file:///你的仓库路径/xuan-theme/obsidian/theme.css

Zed

配色导出（浅色/深色）

  • Xuan Light：zed/xuan-light.json
  • Xuan Dark：zed/xuan-dark.json
  • 导入：Zed 主题设置 → Import Theme

VS Code

配色导出（主题包）

  • 入口：vscode/package.json
  • vscode/xuan-light.json、vscode/xuan-dark.json
  • cd vscode && code --install-extension .
  • cd vscode && npm run package

Obsidian

Canonical entry (Obsidian only)

  • Theme file: obsidian/theme.css
  • Manifest: obsidian/manifest.json
  • Install command: cp /your-repo-path/xuan-theme/obsidian/theme.css ~/.obsidian/themes/Xuan/theme.css
  • file:// example: file:///your-repo-path/xuan-theme/obsidian/theme.css

Zed

Color export (light/dark)

  • Xuan Light: zed/xuan-light.json
  • Xuan Dark: zed/xuan-dark.json
  • Import: Zed Theme setting → Import Theme

VS Code

Theme pack export

  • Entry: vscode/package.json (Xuan Light / Xuan Dark)
  • Theme files: vscode/xuan-light.json, vscode/xuan-dark.json
  • Local install: cd vscode && code --install-extension .
  • Package: cd vscode && npm run package
