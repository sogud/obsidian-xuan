# Security Policy

This project is distributed as open source. If you discover a security issue:

1. Open a **private** report in GitHub Security Advisories:
   - Repository → Security → Report a vulnerability
2. Provide a clear reproduction path and impact scope.
3. If possible, include expected vs actual behavior and version (`manifest` / release tag).

Until a fix is published, please do not open a public issue containing secrets or exploitable details.

## Supported versions

- `master` branch receives active fixes.
- Older release tags are maintained on best-effort basis.

## Scope

- Applies to all files in this repository, including theme outputs and editor export files.
