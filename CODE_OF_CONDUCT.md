# Code of Conduct

## Purpose

We want everyone to feel welcome in this project. Xuan is a community-first open-source
theme and we expect respectful, clear, and constructive collaboration.

## Expected behavior

- Be respectful in comments, code reviews, and issue discussions.
- Focus on design and implementation quality, not personal preferences.
- Use clear language and provide actionable feedback.
- Be concise and practical in requests and PRs.

## Unacceptable behavior

- Harassment, insults, hate speech, or hostility.
- Repeatedly dismissive or off-topic replies.
- Disclosure of private information without permission.
- Malicious use or copying that violates this project intent.

## Enforcement

If behavior violates the above, maintainers may remove content, lock conversations,
or block contributors from the repo workflow for the project’s safety.

## Scope

These rules apply to:
- Issues and discussions
- Pull requests
- Review and maintainer comments

## 适用范围（中文）

- 对项目相关沟通保持尊重，避免人身攻击、歧视与骚扰
- 不得发布他人隐私信息，不得做无意义恶意攻击
- 维护者有权在项目安全与秩序需要时暂停讨论权限或关闭相关渠道
